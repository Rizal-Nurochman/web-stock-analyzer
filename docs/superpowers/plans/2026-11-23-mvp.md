# Rencana implementasi MVP

Gunakan [requirement dan skenario penerimaan](../../requirements.md) sebagai acuan verifikasi setiap tahap.

1. **PostgreSQL, histori, dan indikator** di `app/market/`. Siapkan koneksi SQLAlchemy dan migrasi Alembic pertama, lalu uji migrasi pada database PostgreSQL kosong. Gunakan CSV asli untuk memverifikasi jumlah baris per emiten dan tanggal terakhir. Uji impor ulang, jendela 19 dan 20 sesi, serta konsistensi band saat filter tanggal berubah.
2. **API FastAPI dan dashboard React** di `app/web/` serta `frontend/`. Buat skema respons harga, siapkan proxy Vite, lalu hubungkan pemilih emiten, rentang tanggal, chart harian, volume, dan detail candle. Verifikasi alur BBCA 2018–2020 dan perpindahan ke emiten lain.
3. **Sinkronisasi RSS** di `app/news/`. Periksa ketentuan sumber. Gunakan sampel feed untuk memverifikasi parsing, deduplikasi dan pemulihan saat satu feed gagal. Hubungkan sindikasi otomatis ke panel dan buktikan pembacaan feed asli.
4. **Sentimen dan demo** di `app/news/`, `app/web/`, dan `frontend/`. Petakan ticker dan nama bank, periksa label pada artikel nyata dari empat emiten, lalu verifikasi status Belum dinilai. Sajikan hasil build React dari FastAPI dan uji demo lokal dengan satu worker, termasuk saat koneksi terputus. Catat langkah menjalankan aplikasi di README.
