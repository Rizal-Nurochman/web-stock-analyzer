# Data lokal

Saat fitur impor tersedia, gunakan file asli `BBCA_BBRI_BMRI_BBNI_combined.csv` di folder ini. Baseline terverifikasi berisi 9.605 baris pada 10 Oktober 2016 hingga 8 Oktober 2026.

Database lokal akan dibuat setelah aplikasi dijalankan. CSV dan database dikecualikan dari Git agar data kerja tersimpan di laptop kelompok.
