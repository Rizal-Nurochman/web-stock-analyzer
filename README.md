# Web Stock Analyzer

Dashboard lokal untuk demo Kelompok 3. Pengguna memilih BBCA, BBRI, BMRI, atau BBNI, lalu menelusuri candlestick harian, Bollinger Bands, volume, dan sentimen per artikel.

MVP menggunakan React dan Vite untuk dashboard, FastAPI untuk API, dan PostgreSQL untuk penyimpanan. Repositori ini berisi kerangka arsitektur dan [rencana implementasi](docs/superpowers/plans/2026-11-23-mvp.md).
